# Notebooks

This directory contains Jupyter notebooks for exploratory analysis and interactive execution of the ecDNA classification pipeline.

## Available Notebooks

- **ecDNA_analysis.ipynb**: Interactive version of the full pipeline with visualizations and explanations

## Usage

To use these notebooks:

1. Install Jupyter: `pip install jupyter`
2. Start Jupyter: `jupyter notebook`
3. Navigate to this directory and open the desired notebook

## Google Colab

These notebooks are also compatible with Google Colab. Simply upload to Google Drive and open with Colab.
